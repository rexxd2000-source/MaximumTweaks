A pad only reports at the rate its firmware and driver were built for. Overriding it means rewriting the bInterval on the pad's interrupt endpoint, which is kernel work — a signed USB filter driver. This app ships no driver, so the rate selector is disabled rather than faked.

What these switches actually do. Each one is a single, real Windows setting that the app snapshots before touching it, so Revert all puts the previous value back exactly — including removing the override entirely when Windows was using its default. Settings marked system-wide affect every USB, Bluetooth or scheduling decision Windows makes; per-device and hub rows touch only the controller that is plugged in right now. Some rows need administrator rights or a reboot, and the app tells you when that is the case instead of claiming a change it could not make.
