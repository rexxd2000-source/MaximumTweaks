## Important Details
- **Tier-naming decision (user):** plans stay Foundation ($0) / Performance ($10) / Maximum ($15); tweak classification axis is **FREE / FOUNDATION / MAXIMUM**, mapped order-preserving: FREE→`foundation` plan, FOUNDATION→`performance` ($10), MAXIMUM→`maximum` ($15). `requiredTier` must be **derived from `classification`** (single source of truth). Lock text references the plan via `config/plans.required_tier_label` ("Requires Performance" / "Requires Maximum").
- **Classification axis is uppercase and distinct from plan ids:** `config.plans` constants are lowercase (`'foundation'`, `'performance'`, `'maximum'` — confirmed via probe). `database/classification.py` aliases plan constants (`PLAN_FOUNDATION`, `PLAN_PERFORMANCE`, `PLAN_MAXIMUM`) and defines `FREE = "FREE"`, `FOUNDATION = "FOUNDATION"`, `MAXIMUM = "MAXIMUM"` to avoid vocabulary collision (bug fixed: `tier_for` previously failed closed to the uppercase *grade* `"FOUNDATION"` instead of the *plan* `PLAN_FOUNDATION` — a real vocab collision my new round-trip test caught).
- **No module-level `tier=` pins exist** — `grep` found none; all 863 tweaks get `tier` from the classifier. The new engine is a clean drop-in for `classify_tier` semantics.
- Decision semantics in `_dev/audit_gen.py` (rules): REMOVE for status `INVALID`, disposition `UNSUPPORTED`, `NoAutoUpdate=1` (win-011), and exact-duplicate losers (unless hardware audiences differ — see below); REWRITE for conflict participants, status `OUTDATED`, disposition `BROKEN`, `_disables_critical_repair` (WaaSMedicSvc/wuauserv/usosvc/windefend); KEEP otherwise. Module-name-based DANGEROUS badge (aim/delay_destroyer) does **not** trigger REWRITE; genuinely risky tweaks land in MAXIMUM via flags/critical-service checks instead. The MAXIMUM classifier treats only **critical** services as MAXIMUM; **vendor/audio** stack service changes (nvvapi group) are a warning not a MAXIMUM (nvvapi dict retained).
- Duplicate removal is hardware-audience-aware: exact duplicates removed only when hardware audiences identical; differing-audience pairs (Intel-vs-AMD CPU policies, SSD-gated vs generic SysMain) kept.
- Bugs found and fixed in `_dev/audit_gen.py`: (1) `validation._target()` takes a single **action** not a tweak — fixed by building a sorted set of `(target, value)` pairs from actions.
