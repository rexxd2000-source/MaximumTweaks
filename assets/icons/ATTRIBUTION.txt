Sidebar icons in this folder are colorful glossy icons, each tinted to its
category color (FPS green, System blue, Input red, Tools orange, Profiles
pink, Meta gray). Bundled as PNG assets so the shipped app needs no network
or SVG rendering plugin at runtime; the app draws them as-is (white only on
the active row, matching the reference design).

- 16 icons (Dashboard, CPU, GPU, RAM, Games, FPS boost, Windows/system,
  Storage, Audio, Network, Keyboard, Mouse, Input, Tools, Game profiles,
  Fortnite settings) are the colorful glossy art from the previous sidebar
  design (maximum-tweaks-sidebar-v4.html), recolored to the category hue
  while preserving their gloss/shine.
- 5 icons (Delay destroyer, Smart debloater, Route analyzer, AI assistant,
  Settings) are generated in the same glossy style from the lucide glyphs in
  maximum-tweaks-sidebar-colorcoded.html (ISC, https://lucide.dev/license).
- Smart debloater uses the lucide "broom-sparkles" glyph and Controller
  overclock uses the lucide "gamepad-2" glyph (both fetched from the official
  lucide-static package, https://unpkg.com/lucide-static), rendered in the same
  glossy Tools-amber style (ISC, https://lucide.dev/license).
- 6 category logos regenerated from official open-source marks:
    fpsboost = lucide "gauge" speedometer (ISC, lucide-static)
    system   = official Windows 11 4-pane mark (public-domain simple geometric
               shape; mirrored from devicon "windows11-original.svg", MIT)
    input     = lucide "mouse-pointer-2" cursor (ISC, lucide-static)
    tools     = lucide "wrench" (ISC, lucide-static)
    profiles  = lucide "id-card" (ISC, lucide-static)
    settings  = lucide "settings" gear (ISC, lucide-static)
  Regenerated with assets/icons/_gen_gloss.py using the same glossy pipeline.

Beyond the PNG sidebar set, the application also renders the following
crisp line icons at runtime from inline lucide SVG path data (ISC license,
https://lucide.dev/license; glyphs are re-used verbatim from lucide-static
lucide/lucide-icons, stroke-width 1.5, `fill="none"`):

- Sidebar nav icons and page-header icons: ui/widgets.py NAV_LUCIDE
  (home, cpu, gpu, ram, games, fpsboost/bolt, system/settings gear, storage,
  audio/waveform, network, keyboard, mouse, input/clock, tools/wrench,
  delay_destroyer, debloat/broom-sparkles, route_analyzer/globe, profiles,
  controller/gamepad-2, fortnite/flag, chat/sparkles, search, check, close,
  alert, info, hourglass, ban, shield).
- Dashboard/route pages: ui/pages/settings.py REF_ICONS and
  ui/pages/route_coming_soon.py _LUCIDE (clock, cpu, gpu, ram, storage, os,
  uptime, check, bolt, arrow-up-right).
- These runtime icons are used for status glyphs such as the search field,
  license shield tile, lock/ban and timeout hourglass on the gate screen,
  optimization dialog close, and toast indicators (success/error/warning/info),
  replacing the earlier font-glyph (Unicode character) icons.

Brand logos are bundled the same way — inline SVG path data rendered at
runtime, no network needed. Glyphs come from simple-icons (CC0-1.0,
https://github.com/simple-icons/simple-icons, path data reused verbatim):

- ui/widgets.py BRAND_SVGS + brand_icon_pixmap(): discord, steam, epicgames,
  riotgames, battledotnet. Rendered on the "Join Discord" button (About page),
  the gate "Contact support" buttons, the game profile cards, and the premium
  game-list platform tags. Microsoft/Win11 has no Simple Icon glyph (removed
  from the set), so the Microsoft platform keeps its text tag.
- Simple Icons is CC0-1.0; brand marks remain property of their owners.

Dock logos (added 2026-10-06; recolored 2026-10-07)
----------------------------------------------------
assets/icons/dock/*.png are monochrome silhouettes used only by the bottom
dock (ui/dock_nav.py + ui/dock_nav.html). The dock's orbs already carry the
per-category colour, so the artwork on top is tinted to the app's neon-violet
accent rather than a second competing colour. Every category has its own
distinct glyph -- no two keys share the same silhouette. Rendered at
512px from their source SVGs and downscaled to 128px:

- Font Awesome 6 Free Solid (CC BY 4.0, https://fontawesome.com/license,
  https://github.com/FortAwesome/Font-Awesome) glyphs, tinted to the app's
  neon-violet accent (#C484FF, the light member of the THEME accent pair
  #8B6BFF/#C484FF):
    gauge-high (FPS boost / gauge), display (Windows / System & monitor),
    crosshairs (Pointer & Input), wrench (Tools), id-card (Game profiles),
    gear (Settings), microchip (CPU), memory (RAM), gamepad (Games),
    hard-drive (Storage), volume-high (Audio), wifi (Network), hourglass
    (Network QoS), keyboard, computer-mouse, stopwatch (Delay Destroyer),
    broom (Smart debloater), route (Route analyzer), chart-line
    (Diagnostics), bullseye (Fortnite), message (AI assistant).
- Bootstrap Icons (MIT, https://icons.getbootstrap.com,
  https://github.com/twbs/icons) glyphs, same neon-violet tint:
    gpu-card (GPU), joystick (Controller overclock), grid (App Optimizers).
- Source SVGs fetched live from
  raw.githubusercontent.com/FortAwesome/Font-Awesome/6.x/svgs/solid and
  raw.githubusercontent.com/twbs/icons/main/icons.
